# Harmony rework plan (replaces Disharmony)

Status: **design agreed with the owner 2026-10-07, not started.** Target Bedrock 1.26.52 / Script API 2.8.0.
Replaces design KB section 10 and the "Disharmony core" section of `docs/TECHNICAL_NOTES.md` once built.

## 1. Model

One per-player number, **harmony**, an integer from **-60 to +10**. One point is worth one minute of peaceful time in the forest.

| Rule | Value |
|---|---|
| New player / start | 0 |
| Inside the forest, no deed | +1 per 60 s, up to +10 |
| Outside the forest | +1 per 120 s, but never above 0 (positive harmony is kept, not raised) |
| Floor | -60 (worst case: 1 h inside or 2 h outside back to 0) |
| A deed | restarts the minute timer (no credit for the partial minute) |
| Above 0, a cost counts double | penalty p at harmony h > 0: the first min(p, h/2) points cost 2 each, the rest 1 each. Example: h = 4, animal (3) -> -1 |

**Where a deed counts:** when the player **or** the victim is inside the forest ("the forest sees what happens inside it"; closes border sniping both ways).

### Deed costs

| Deed | Cost | Notes |
|---|---|---|
| Animal (any non-monster mob: deer, swan, squirrel, vanilla animals, villagers...) | -3 | Not family `inanimate` (armor stands) |
| Monster (family `monster`, `entity.matches({families: ["monster"]})`) | -1 | Deliberate: lead monsters to the wardens, who kill for free (owner wants that tactic) |
| White deer | -6 | |
| Unicorn | -10 | The forest's most sacred creature |
| Fighting a warden | -1 per fight | A fight = first player hit on a warden after 60 s without one (`provoked` map in `elven_warden.js`, `PROVOKE_MS`) |
| Killing a warden | -6 | On top of the fight cost |
| Killing a player | -3 | |
| Kills by tamed wolves, fall, lava etc. | 0 | Only `damageSource.damagingEntity` = player (projectiles included), as now |
| Chopping wood, picking flowers | 0 | **No plundering penalty in v1** (owner). Keep a single `recordDeed(state, kind)` entry point so plundering costs or care rewards (planting acorns...) are a table entry later |

**Death:** changes nothing, **except** dying inside the forest while Hated: harmony is set to **-29** (top of Shunned). Wardens stop shooting,
trading stays refused. Prevents both a "die to reset" exploit and warden spawn-camping at a bed in the forest.

## 2. Bands

| Harmony | Band | Icon color | Icon shape (color-blind safe) | Wildlife wariness | Gifts / taming | Trades (later) |
|---|---|---|---|---|---|---|
| +10 | Friend of Lothlórien | bright green | full mallorn leaf with a star | `friend` (3) | yes | all + Friend-only (elven bow...), best prices |
| 0...+9 | Guest | green | plain leaf | `calm` (10) | "untrusted" | normal stock and prices |
| -1...-14 | Uneasy | orange | wilted leaf | `l1` (13) | "restless" | fewer items, higher prices |
| -15...-29 | Shunned | red | thorn / broken twig | `l2` (20) | "restless" | refused; Loremaster: "Learn to live in peace with the forest, then return." |
| -30...-60 | Hated | dark red | dark eye | `l3` (30) | "restless" | refused; **wardens shoot on sight** |

Friend is +10 only on purpose: any single bad deed loses it (a monster kill at +10 costs 2). Any negative value already shows that the
forest dislikes you. The Uneasy/Shunned boundary (-15) is a starting value. The wildlife states and radii are the existing ones, so the
entity JSON of deer, white deer, swan, squirrel and unicorn does not change.

Consumers to switch from `levelFor`/`isFriend` to `bandOf(harmony)`:
- `deer.js` / `deer_rules.js` `warinessFor` (band -> wariness, table above).
- `squirrel_rules.js`, `white_deer_rules.js`, `unicorn_rules.js` `offerRefusal`: "restless" when harmony < 0, "untrusted" for Guest, go ahead for Friend.
- `white_deer.js` `canBeGuided`: a guidance in progress continues while Friend (as today it ends on any kill).

## 3. Display

- **Action bar, inside the forest only:** `<icon> <band name>` for every band (Guest too). No pips, no number. Number only in the debug readout.
  The action bar stays reserved for this status (existing test "the actionbar is only the ... status").
- **Icons:** custom font glyph page in the RP, `lothlorien_rp/font/glyph_E5.png` (256x256, 16x16 cells, like vanilla `glyph_E1`), characters
  U+E500...U+E504. Vanilla 1.26.52 uses pages E0, E1, F9-FF (checked on disk); E2-F8 are free, but another add-on may use the same page
  (risk accepted, note it in the README). Generated by a script `tools/make_harmony_icons.py` (bedrock-art skill). **Not yet tested in this
  workspace**: first step of phase 2 is a one-glyph spike.
- **Chat:** one message per band change in each direction, with flavour (e.g. Uneasy: "The forest frowns upon your deeds.", Hated: "The
  wardens will no longer suffer your presence.", back to Guest: "The woods forgive you."), Friend gained / lost as now. A deed that does not
  change the band gets a short hint ("The trees grow quiet around you."), at most once per 30 s per player.
- All texts through `messages.js` and `localization/catalog.json` (9 locales, workflow in `docs/LOCALIZATION.md`; `.\mods localize build lothlorien`).
  Retire the `disharmony.*` and `status.disharmony` keys.

## 4. Hated: wardens attack on sight

- The script keeps a player tag `lothlorien_hated` in step with the band (set on entering Hated, removed on leaving, checked on join).
- `entities/elven_warden.json` `nearest_attackable_target`: add an entry for players with `has_tag lothlorien_hated` (verify the filter with
  `bedrock-lookup` first).
- `elven_warden_rules.js` `isFriendlyFire`: a hated player is never shielded (like a provoked one). Test table extended.

## 5. Trades and Loremaster (later phases; elf traders do not exist yet)

- Native trade screen with per-player tables: one `economy_trade_table` component group per band (Friend, Guest, Uneasy), `persist_trades: false`.
- Script **pre-swaps** the trader's table to the band of the player near it / looking at it (every ~10 ticks), so one click opens the right table.
  Script cannot open a trade screen itself (no trade API in 2.8.0), so "cancel, then open later" is not possible.
- `world.beforeEvents.playerInteractWithEntity` (cancellable in 2.8.0): refuses Shunned / Hated with a chat line; on a band mismatch
  (two players at one elf) cancels, swaps, and the player clicks again.
- Bedrock cure discounts are global (not per player), Hero of the Village only discounts and leaks to vanilla villagers: not used.
- Loremaster: dialogue chosen by band; Shunned/Hated get only the refusal line.

## 6. Code changes (phase 1)

- `scripts/disharmony.js` -> `scripts/harmony.js` (pure, no `@minecraft/server`): constants above, `newState`, `bandOf`, `deedCost(kind)`,
  `applyPenalty` (double above 0), `recordDeed`, `recordDeath(state, insideForest)`, `tick(state, inside, dt)`, `statusText`, `serialize`/`parse`.
- `scripts/disharmony_game.js` -> `scripts/harmony_game.js`: deed classification on `entityDie` (player-or-victim inside, families via
  `entity.matches`), warden-fight hook exported for `elven_warden.js`, death rule, the hated tag, chat hint rate limit.
  **Save only when harmony changes** (today it writes the dynamic property every second for every player).
- Storage: dynamic property `lothlorien:harmony` = `{harmony, timer}`. **No migration** (owner, 2026-10-07: only test worlds exist);
  the old `lothlorien:disharmony` property is simply ignored.
- Debug: `/scriptevent lothlorien:harmony [value]` shows or sets harmony; drop `lothlorien:disharmony`.
- `main.js` wiring, `KILL_WEIGHTS` removed (costs table in `harmony.js`).
- `tests/run.mjs`: replace the `disharmony:` tests (levels, decay, death, Friend, status, white deer weight, warden weight) with harmony tests:
  recovery inside/outside and the 0 cap outside, the double-cost rule (h = 4 animal -> -1; h = 10 monster -> 8), floor, every deed cost,
  Hated death -> -29 and other deaths unchanged, band table incl. edges (10, 9, 0, -1, -14, -15, -29, -30), junk tolerance,
  consumer mappings (wariness, refusals).

## 7. Phases

1. **Core** (section 6) + consumers. Verify, deploy, test in game with the debug command.
2. **Display**: glyph spike, icons, action bar, chat messages, localization.
3. **Hated**: tag, warden JSON, friendly fire.
4. **Docs**: KB section 10, `TECHNICAL_NOTES.md` (new section, old Phase 9 marked superseded), `docs/mobs/*.md` Disharmony rows,
   settlements plan trade states, README line, `NOT_IMPLEMENTED.md`. Shared knowledge (glyph page technique once verified) into
   `.claude/skills/` (separate workspace commit).
5. Later, with the settlements: trades (section 5) and the Loremaster.

## 8. In-game checks

1. `/scriptevent lothlorien:harmony` shows 0 for a new player and sets values for the checks below.
2. Stand in the forest: +1 per minute up to 10; outside from -5: +1 per 2 min, stops at 0; outside from +6: stays 6.
3. At 10 kill a zombie: 8, Friend lost. Lead a zombie to a warden: no change.
4. Shoot a deer standing outside from inside, and one inside from outside: both cost.
5. Set -30: wardens shoot on sight; die to them inside: -29, they stop. Die to a fall at -20: stays -20.
6. Icons render in the action bar at every band, readable in light and dark scenes; chat hints not spammy while hunting a herd.
7. Wildlife flight distances per band as the table; squirrel/white deer/unicorn refusals as the table.
