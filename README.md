# Lothlorien

A rare, peaceful Lothlórien biome for Minecraft Bedrock: Mallorn trees, Elven flora and
structures, gentle fauna and the Disharmony mechanic.

Namespace: `lothlorien:`

Packs: `lothlorien_bp/` + `lothlorien_rp/`. Deploy with `mods deploy lothlorien` from the workspace.

- Design: `docs/design/` (concept, knowledge base, phased implementation plan)
- Technical findings and test checklists: `docs/TECHNICAL_NOTES.md`

## Status

- Phase 0 (skeleton) — done.
- Phase 1 (biome spike) — biome, client colours and fog written; awaiting in-game test.
